# CyberNet 97 Rules

This is a fictional 1997 Internet portal.

Technology:
- Python Flask
- SQLite
- Jinja2 templates
- HTML/CSS

Never:
- modernize the UI
- replace the retro style
- rewrite everything
- delete the database

Before changing code:
- inspect existing routes
- inspect templates
- inspect database tables
- check existing features

After changes:
- run Flask
- test routes
- check forms
- fix errors
